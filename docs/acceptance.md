# 桌面客户端验收

2026-11-07，macOS arm64。范围来自 design.md、architecture.md、六份 ADR 及后续对统一 Composer 和会话时间线的要求。

| 验收项 | 核验依据 | 实测范围与观察 |
| --- | --- | --- |
| 本地工作台、技术栈 | Electron 主进程、独立 utility、SQLite、React/TS、Tailwind、shadcn；生产构建及 arm64 应用启动。Composer 源码位于本项目。 | 当前包未签名。 |
| 单一输入区和作品会话 | 已在原生工作台操作两种提交方式、设置弹层与图库。960×680 和 1480×980 截图可见用户右侧气泡、Agent 左侧署名和底部单卡片。真实模型在重开作品后找回随机约定。 | 已核验这两种窗口尺寸。 |
| BYOK 和模型能力 | 系统加密保存配置。真实兼容模型完成结构化输出、工具调用和图片识别；文本和视觉配置可分别指定。 | 其他服务需在设置中自行运行能力检查。 |
| 版本与素材 | 旧版本完整快照、用户编辑接管与分支父版本有回归测试；图库实机比较两张真实原图。系统保存面板导出的 WebP 与归档文件逐字节相同。 | 打包版添加双人偶，再更新为三人偶，退出后重开仍能编辑红、蓝、绿三个人偶。 |
| 目录与生成 | 真实模型/LoRA 搜索、Recipe 搜索和封面；手动及 Agent 单图任务均完成本地归档。保存有序 Recipe ID、模型版本、请求和远端 ID。 | Tsubaki.3 任务 2075764205010775186 同时使用已上传素材与指定 Recipe，保存了 1024×1024 原图。画面保留花色并引入人物；未能准确保留白墙构图。 |
| Prompt Helper | 中文短想法的强化前后同模型、同 Seed、各一张原图对照；素材标记和触发词有确定性校验，锁定语义另行检验。接受和撤销记录实际文本。 | 真实双人完整 Prompt 已验证左右角色、动作、参考标记、触发词及相斥镜头。单 Seed 样例尚未建立模型专用画风质量结论。 |
| Agent 创作闭环 | 实测生成、等待、下载、看原图、回复。已验证只推荐和检索预设的真实请求无生图；已选原图与较新的同版本图片可区分。 | 两轮实测按线稿→看图→上色→看图推进。修复跨视觉工具的完成状态判定后，在原执行上恢复结案；共 2 张、8 次调用。 |
| 暂停、额度和恢复 | 测试覆盖用户编辑、停止后阻止生成、剩余额度、未知提交不重发、人工核实和下载退避。Electron 原生进程重启后 SQLite 恢复通过。 | 隔离 Electron 中实测强制终止 utility 后，主进程重建服务，原窗口恢复 IPC，隐藏状态、远端 ID、未知提交及额度均符合预期。 |
| 偏好和预设 | 手动保存及加载、Agent 搜索、按指定版本发起保存建议。实测确认前偏好不生效，确认后可跨作品使用。 | 用户实际的审美采纳率需根据其使用记录判断。 |

按能力复验的脚本在 scripts 下。真实生图脚本会消耗账户额度，历史结果、具体任务和样例观察见 implementation-progress.md。

## 最终构建

- 160 项自动化测试、lint、TypeScript 和生产构建通过。Electron 真实进程重启、崩溃恢复与缩略图和原图的协议读取通过。
- 已从 release/current/mac-arm64/PixAI Desktop.app 实际启动，打开双轮作品可见已完成、2/2 张、8/14 次模型调用及两个可预览版本。
- 应用内前端 JS、CSS、HTML 以及 main、preload、worker 与当前构建逐字节一致。包内没有 .env。测试机没有 Developer ID，交付的是未签名的 Apple Silicon 本机包。
