# 首版包含受限的自动创作循环

首版创作 Agent 覆盖理解目标、准备方案、生成、看图检查、按需调整再生成和交付，在用户约定的消耗上限内自主执行。对于未满足明确要求的结果，Agent 可以尝试自动修正；审美取舍交给用户，以兼顾减少手工操作与保留创作控制权。

默认先生成 2 张，每次自动创作总计最多 6 张，自动修正最多 2 轮；用户可在启动前修改上限。满足明确要求、额度用完、连续修正无改善或无法判断下一步时，交付现有结果并说明情况。用户停止后不再提交新生成。

张数预算按已提交的请求张数累计，失败和提交结果不明也占用额度；查询及下载重试不重复计数。提交结果不明时暂停，避免自动重复生图。每次 Agent 执行默认最多 20 次语言／视觉模型调用，包含重试；模型调用上限也可在启动前调整。以上为执行限额，实际积分与模型费用另行记录，不承诺精确的货币上限。

用户未指定模型与 LoRA 且明确要求生成时，Agent 可自主查找并采用推荐方案；只要求推荐时展示方案。用户编辑 Composer 后，保留已提交任务的结果，并暂停旧目标的后续自动生成；用户选择“按当前草稿继续”后再围绕新目标执行。

关闭窗口可在后台继续，明确退出应用后停止本机执行。重新打开时自动查询已知任务并下载结果，新的生成等待用户点击“继续”；此前因用户编辑而暂停的执行保持暂停。
