# 工作台视觉基准

基准图：`concepts/workbench.png`。按最新反馈，Agent 已并入底部 Composer，输入框上方默认显示会话时间线，图片浏览与比较可切换到图片视图。示例作品与图片仅用于视觉参考，正式应用从真实持久记录加载，不伪造生成结果。

## 设计系统

- 背景白色 `#ffffff`，画布浅灰 `#f8f9fc`，边框 `#e4e4eb`。
- 正文 `#18181b`，次级文字 `#71717a`，主要操作紫色 `#7c3aed`。
- Geist 字体，中文使用系统无衬线字体。正文 14px，辅助文字 12px，作品标题 24px。
- 左导航宽 220px，小窗口缩至 170px。结果区和底部 Composer 使用其余宽度。
- 间距 4/8/12/16/24px，控件圆角 8px，图片边框圆角 8px。
- 使用现有 shadcn/Radix 组件与 Lucide 图标；键盘焦点可见，遵守减少动画设置。
- Settings 使用同一色系的 BYOK 表单；空作品、错误、生成中、版本比较和 Prompt 修改预览共享设计系统。

## 明确的适配

时间线和 Composer 对齐在同一条宽度不超过 980px 的内容列。自己的发言靠右，使用浅紫色气泡和“你”的署名。PixAI Agent 靠左，带星形图标和署名；结果图使用独立卡片。底部保留单一白色编辑框，素材和输出设置在框内顶部，模式切换、强化、创作设置与发送在框内底部。额度、锁定要求及预设保存通过创作设置弹层访问。

实际界面以中文为默认语言，沿用 Composer 的国际化支持。基准中的示例作品、时间、进度和图片不是种子数据。保留现有 Composer 的真实编辑与 3D 能力，控件内容由功能所需而扩展。
